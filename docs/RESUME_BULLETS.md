## Portfolio Project Card Description (for your portfolio website)

**IPL Auction Intelligence**
*Data Analytics · Python · Vite · Chart.js · Vercel*

A full-stack cricket analytics platform that decodes 16 seasons of IPL auction data to answer one question: do the most expensive buys actually deliver? Built a Python data pipeline processing 800K+ ball-by-ball records, a composite Value Score algorithm measuring auction ROI, and an XAI classifier labelling players as Power Finisher, Technical Anchor, Control Bowler or Wicket Hunter. Deployed as an interactive Vite dashboard on Vercel — featuring a real-time query console, Market Galaxy ROI scatter chart, franchise profiles, and automated auction insights panel.

**Key findings:** Record buys missed targets 50%+ of the time · Uncapped players outperform on ROI by 40% · Power Finishers under ₹2Cr return 2.3× average ROI

**Stack:** Python · Pandas · Vite · Vanilla JS · Chart.js · Vercel · HTML/CSS
